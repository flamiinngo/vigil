# Vigil — Decentralized On-Chain Intelligence Network

> **ETHGlobal Open Agents 2026**  
> Prize tracks: Gensyn AXL · Uniswap Foundation

Vigil is an open, decentralized network of independent nodes that watch Ethereum smart money wallets and reach consensus when coordinated accumulation is detected — all without a central server, shared database, or trusted coordinator.

Anyone can run a node. Every node strengthens the network. Signals only fire when independent nodes independently agree.

---

## Vision

On-chain alpha has always been centralized. A company runs the server, curates the wallet list, and decides what you see. If their infrastructure fails, you're blind. If they're compromised, you get noise.

Vigil is built on a different model: a permissionless network of operators, each watching their own independently discovered wallet slice, coordinating observations over an encrypted P2P mesh. No operator sees another's wallets. No single point of failure. No subscription gate. The network gets smarter as more nodes join — not because of a company's curation, but because independent agreement is harder to game.

This is what decentralized intelligence infrastructure looks like.

## How It Works

### Each node watches its own wallets

When you run `discover.py`, Vigil scans the last ~3,000 blocks of Uniswap v3 Swap events across 18 major pools and collects `tx.from` — the actual EOA that signed each transaction. Wallets that appear consistently across many different pools score higher (pool diversity is a reliable proxy for sophisticated traders). The result is a scored list of 100 smart money wallets, freshly discovered from on-chain activity.

This wallet list belongs to your node. When multiple nodes run on the network, each has its own independently discovered set — meaning observations from different nodes are genuinely independent, not duplicates.

Each node monitors its assigned wallet slice for ERC-20 Transfer events in real time. Stablecoins are filtered. Every inbound accumulation event is recorded and broadcast to peers.

### Observations travel over Gensyn AXL

[Gensyn AXL](https://github.com/gensyn-ai/axl) is an encrypted peer-to-peer mesh network. When a node detects a wallet accumulating a token, it encrypts the observation and broadcasts it to all connected peers via AXL's local HTTP API:

```
POST /send   →  encrypted observation to peer
GET  /recv   →  drain inbound observations from peers
GET  /topology  →  discover connected peers
```

No relay server. No shared API. Operators connect directly. Observations stay private in transit — only the receiving peer can read them.

### Consensus requires independent agreement

A signal fires when **2 or more distinct wallets** — across any combination of nodes in the mesh — accumulate the same token within a 20-minute window. It doesn't matter which node saw which wallet. What matters is that multiple independent wallets made the same move.

This is wallet-convergence consensus. A single whale moving into a token is watching. Two whales from different wallet lists, detected by different nodes, coordinating without knowing each other — that's a signal.

When a signal fires, it's enriched with live Uniswap v3 data (price, liquidity, 24h volume) and a one-line AI narrative generated by Groq. Every signal is verifiable on-chain.

### The network grows with every new node

When a new operator joins:
- They run their own `discover.py` — independently discovering their own wallet set
- They connect their AXL node to the mesh
- Their observations immediately strengthen consensus
- Tokens seen by more independent nodes carry higher confidence

There is no registration, no approval process, no token required.

## Running Your Own Node

**Requirements:** Python 3.10+, Node.js 18+, Gensyn AXL binary

### First-time setup

```bash
git clone https://github.com/YOUR_USERNAME/vigil
cd vigil
pip install -r requirements.txt
cd frontend && npm install && cd ..
```

Create `.env` in the project root:

```env
ETH_WS_URL=wss://ethereum.publicnode.com
ETH_RPC_URL=https://1rpc.io/eth
NODE_ID=vigil-node-3
AXL_URL=http://localhost:9006
API_PORT=5050
GROQ_API_KEY=your_groq_key_here
```

No paid RPC required. Public endpoints work.

### Discover your wallet set (run once)

```bash
cd agent
python discover.py
```

Scans Uniswap v3 on-chain activity and builds your local `wallets.json` (~2 minutes).

### Start your AXL node

Create `axl/my-config.yaml`:

```yaml
listen_addr: "0.0.0.0:9005"
rest_addr: "0.0.0.0:9006"
bootstrap_peers:
  - "BOOTSTRAP_PUBKEY@BOOTSTRAP_IP:9001"
```

Get the bootstrap peer address from an existing network operator.

```bash
cd axl
.\axl.exe -config my-config.yaml
```

### Start all services (4 terminals)

```powershell
# T1 — Vigil intelligence node
cd agent
python main.py

# T2 — API server
cd agent
python server.py

# T3 — Dashboard
cd frontend
npm start
```

Open **http://localhost:3000** — you're live on the network.

## Running the Full Network Locally (2 nodes)

To run both nodes on one machine for development or demo:

```powershell
# T1 — AXL node 1
cd axl; .\axl.exe -config node1-config.json

# T2 — AXL node 2
cd axl; .\axl.exe -config node2-config.json

# T3 — Vigil node 1
cd agent; python main.py

# T4 — Vigil node 2
cd agent
$env:NODE_ID="vigil-node-2"; $env:AXL_URL="http://localhost:9004"; python main.py

# T5 — API server
cd agent; python server.py

# T6 — Dashboard
cd frontend; npm start
```

## Safety Layer

Every token surfaced by Vigil is checked against [GoPlus Security](https://gopluslabs.io/) before being shown. Signals are tagged:

- `✓ SAFE` — open source, no honeypot flag, normal taxes
- `⚠ CAUTION` — high sell tax, mintable supply, or suspicious ownership
- `✗ HONEYPOT` — cannot sell; filtered from actionable signals
